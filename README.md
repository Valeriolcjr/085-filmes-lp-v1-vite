# 085 FILMES — LP V1 (Vite)

## Como rodar localmente

No terminal, dentro desta pasta:

```bash
npm install
npm run dev
```

O Vite exibirá um endereço local, normalmente:

```text
http://localhost:5173
```

## Como gerar a versão de produção

```bash
npm run build
```

A versão final será criada dentro da pasta:

```text
dist/
```

Para testar o build:

```bash
npm run preview
```
